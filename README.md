# Soundcraft Piano Service

鋼琴服務公司官方網站（純靜態網頁，透過 GitHub Pages 發佈）。

## 檔案結構

- `index.html` — 首頁
- `booking.html` — 預約頁
- `booking.js` — 預約表單的前端邏輯
- `assets/` — Logo 圖檔（頁面實際使用 `logo-h-tight.png` 與 `logo-h-light-tight.png`）

## 如何更新網站

1. 直接編輯 `index.html` 或 `booking.html`
2. 用瀏覽器打開檔案確認畫面正確
3. commit 並 push 到 `main`，GitHub Pages 會在幾分鐘內自動更新

## 未納入版本控制

設計稿匯出的備份檔（`*.dc.html`、`Soundcraft Piano Service - *.html`、`uploads/` 等）留在本機，不上傳，詳見 `.gitignore`。
